# web_mujoco

Mac 上的纯网页 MuJoCo WASM 演示：用官方 `@mujoco/mujoco` 在浏览器里加载
`rs_grasp_scene.xml`。不启动 ROS；可选通过本地串口桥把夹爪接触力输出到飞特 HLS3604M。

当前完成到 **M2**（物理步进）。抓取见下方里程碑。

## 环境

- macOS / Linux，Node.js 20.10+
- Chrome 或 Edge

## 启动

```bash
cd web_mujoco
npm install
npm run dev
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。首次会下载约 62 MB STL，之后走浏览器缓存。

本地校验物理（不需要浏览器）：

```bash
npm run smoke
npm run test:explode
```

## 飞特 HLS3604M 夹爪力反馈

在仓库根目录执行 `bash scripts/feedback_conda.sh start`，打开
[http://127.0.0.1:8766](http://127.0.0.1:8766)，在“飞特力反馈”卡片的“舵机串口”下拉框中手动选择端口，再点击“连接舵机”。
串口桥启动时不占用串口，插拔设备后点击“刷新端口”；断开连接、采样超时或串口故障后会卸力并释放端口。
连接期间锁定端口选择，先断开即可换选其他端口。Linux 优先显示稳定的 `/dev/serial/by-id/` 路径。
使用已创建的 conda 环境，不需要 ROS 或真实机械臂。
按住测试按钮输出幅值 10（受面板上限约束），夹持时按状态生成 0–150 的电流幅值。
默认接触力增益 3.5，力度基准 20 N；叠加弹簧、阻尼后幅值上限 150，初触上限 45。参数可在面板实时调整；离开页面或采样超时会卸力。

默认开启“角度控制夹爪”：连接时当前角度设为 50 mm 并设置单向张开挡墙，往合拢方向转动 1° 对应网页夹爪减少 0.5 mm，
范围 0–50 mm。可用“当前位置设为 50 mm”重新定位挡墙或反转方向；该功能不修改实物舵机校准。
启用时由手柄控制夹爪，取消勾选后可继续自动抓取。

修改代码后执行 `npm run build`；开发模式的 `/feetech/` 请求代理到 8766。
`npm run test:feedback` 验证网页接触采样和数据发送。
完整供电、串口与安装说明见[使用手册](../USER_MANUAL_ZH.md#15-网页-wasm-mujoco--hls3604m-夹爪力反馈)。

## 交互功能

- 爆炸时间线：先播放整机展示动作，再按夹爪、J6 → J1、基座分阶段拆解；支持拖动进度、暂停和反向还原。
- 防重叠布局：最终位置通过 AABB 分离计算保留 14 mm 间距，并保持在地面上方。
- 零件探索：可直接点击模型或从列表选择零件，查看名称、所属组件、关节、材质和用途说明；支持高亮、隔离与清除选择。
- 双相机画面：侧栏显示全局俯视与 RealSense D405 腕部视角，可切换横排或纵列；纵列中的每一路均可折叠，总开关会同时停止渲染并收起画面。
- 干净相机输出：TCP 球体、拖拽目标、误差线、选中框和 HTML 准星仅用于主界面，不进入相机画面。
- 腕部模型：默认显示与 RS 控制台同源的 D405 支架和相机本体，安装位置与光学坐标来自装配 URDF，并提供独立的模型显示开关。共享 MuJoCo 模型还包含供 ROS 桌面仿真切换的 D435i 和 Gemini 2 装配。
- 爆炸视图和零件选择只改变 Three.js 显示，不修改 MuJoCo 物理状态。

M0（空场景验证 WASM）已跳过，直接加载 RS 抓取场景。

### M1 运动学（已完成）

加载 `rs_grasp_scene.xml`，滑块直接写 `qpos`，再调用 `mj_forward`。没有 `mj_step`。

验收：

- 手臂、桌面、红/蓝/黄物体可见
- J1–J6 连续转动，模型不瞬移（运动学直连）
- 夹爪滑块同时驱动 `joint7` / `joint_left` / `joint_right`
- 复位回到零位

### M2 物理（已完成）

机械臂六轴使用与 `mujoco_sync.py` 对齐的 PD；网页夹爪单独使用快速响应参数
`Kp=1800、Kd=18`，取代原来的 `300、40`。滑块和舵机都只改目标，
由 `mj_step` 驱动 `<motor>`，夹爪受碰撞约束且驱动力上限仍为 150。
物体可被推倒、掉落。提供 Reset。

显示约 60 Hz，每帧 4 步（`timestep=0.001`，等效约 240 Hz）。

验收：

- 拖 joint2 时手臂有惯性，不瞬移
- 色块受重力，可被碰到
- Reset 回到初始姿态与物体位置

这步之后才算浏览器里代替了原生 MuJoCo 仿真本体。

### M3 页内抓取

读 `red_cube` / `blue_block` / `yellow_cylinder` 的 `xpos`，用简化笛卡尔接近（固定姿态 + 位置 IK，或写死关节路点）：开爪 → 到上方 → 下探 → 闭合 → 抬升。目标会放回桌面上的对应颜色收纳区；叠叠乐模式按蓝、红、黄的顺序堆叠。放置阶段使用接触判断，碰到收纳区或已有堆叠层即松开。

叠叠乐每放好一层都会保持撤离高位，先重新规划到非零的高位抓取准备姿态，再规划到下一个物体，不再中途回零。层间准备姿态采用 J1=0、J2=31.6°、J3=15.4°、J4=18.5°、J5=2.7°、J6=0°。成功或失败时，机械臂会读取浏览器主视角的实时方位，用 J1 面向当前用户视角并将 J4 调整到约 45.8°，使腕部相机保持竖直；随后成功动作由 J6 左右扭头、J5 歪头并将夹爪闭合再张开，失败动作执行低头害羞，最后均停在面向用户的高位中姿态。

侧栏也提供独立的物体移动模式：选择红、蓝、黄目标后，可用方向键面板或键盘方向键 / WASD 在桌面内移动。控制器会保持物体竖直并贴合桌面，同时限制桌面边界和物体重叠；自动抓取运行时会锁定该模式。

验收：

- 点击抓取后物体 `z` 升高
- 不依赖 ROS 视觉话题；成功判据来自 MuJoCo body 位姿

### M4 全局与腕部相机（已完成）

将场景里的 `overhead_rgb` 和安装在 `gripper_end` 上的 `wrist_rgb` 分别离屏渲染到侧栏，两路画面并排显示并由同一个开关控制。颜色检测仍可直接读取 body 位姿，不必依赖 OpenCV。

### 夹持状态与实时调参

“飞特力反馈”卡片支持空载、碰到物体、已夹稳、主动张开、滑移状态。
左右指须持续接触同一物体才确认夹稳。初触时锁定接触开度，后续夹稳、继续压入均不移动挡墙。
使用位置＋限流模式（33=0）：WORD42 写固定墙壁角度，WORD44 实际值始终为 0–150，
WORD46 只限制向墙边回正的速度，默认 2 档（约 8.78°/s）。只在继续合拢的一侧输出。
本地读取角度后判断张开，反向位移默认 0.35° 即关闭输出；跨到墙的自由侧同样立即卸力。
释放绕过平滑，停住不会重新上力；主动重新合拢 0.35° 并回到墙边才恢复阻力。
接触消失、滑移、方向/比例修改、设零点、断连、超时和故障均清除旧墙并卸力。

面板可调增益、角度比例、幅值上限、弹簧刚度、阻尼、力度基准、挡墙保持力度、
张开卸力灵敏度、回正速度上限；高级参数包含重新合拢确认角度、接触与滑移阈值及输出平滑。
显示夹持状态、左右接触力、墙壁角度、挡墙/释放状态、压入量和三个力分量。
参数实时生效并保存在浏览器。默认比例 0.5 mm/°、增益 3.5、上限 150、保持力度 35。
旧参数“张开残余阻力”和“滑移脉冲”不再参与实际墙壁输出；界面隐藏这两项，保留数据兼容。
首次捕获的主动回正最多 2°（另加至多一个编码器计数的量化误差），工厂角度限制只读，越界目标拒绝输出。
改变目标位置或回正速度前，先关闭扭矩并清零电流与速度，再写新目标并使能。
断开、超时与故障同时清零电流和速度并关闭扭矩。
详细状态规则和默认值见 `USER_MANUAL_ZH.md` 第 15 节。

参数范围由前后端共享 `haptic_settings.json`，前后端均校验。串口桥每次等候 10 ms 后
读取角度并判断单向卸力，实际周期包含串口耗时；页面暂停、离开或超时会卸力。
原有可选 ROS 反馈节点保留恒速＋限流模式，网页单向挡墙由本机 WASM 桥提供。

夹爪左右指接触力总和严格大于 **20 N** 时，立即在当时的手柄角度建立硬墙，
直接使用面板输出上限（最多 150），绕过初触限制、夹稳等待和输出平滑。
反向张开仍立即卸力；同一接触期间小幅降到 20 N 以下保留原挡点，
接触消失、滑移、重标定或断连则清除。50 mm 最大张开挡墙仍独立生效。

换算后的 **0 mm 闭合端**也默认形成单向挡墙：继续合拢时使用面板输出上限顶住，
往张开方向自由退回。该挡墙与 50 mm 张开端及超过 20 N 的接触硬墙各自独立，
无需物体接触；重新标定、方向或比例修改时按新的映射更新边界。

在 0–50 mm 两端之间、没有挡墙正在出力时，舵机以原始电流指令 **30**
朝标定的 **50 mm** 位置回弹，形成扳机预紧手感。挡墙优先，回弹受面板输出上限限制；
到达端点、测试、断连、超时或故障时不继续发送自由行程回弹指令。

扳机回弹使用恒速＋限流模式，速度方向直接取夹爪映射方向：
`d(开度)/dt = 角度比例 × 映射方向 × 舵机速度` 为正，朝 50 mm 增大；
反转映射时同步反转速度。电流幅值始终为非负 30（受面板上限限制），不编码电流方向位。
进入任一挡墙时恢复位置模式；模式切换先关闭输出、清零电流和速度，再切换并读回确认。

零位墙边也保留 **30** 的朝 50 mm 回弹预紧力，覆盖零位附近一个编码器计数的量化范围。
继续压过该范围时，零位硬墙恢复顶住；超过 20 N 的接触硬墙仍优先。

角度读取失败（含超时、串口异常和无效角度）时，立即只读补查舵机状态 65，
通信正常则继续读取输出开关、运行模式、电压和温度，随后按故障流程卸力并断开。
状态响应即使带告警位也保留有效数据；状态通信失败则停止额外补读，避免累积超时。
原始角度错误、状态位、各次通信结果及时间保存在 `/feetech/status` 的 `angle_error`，
并写到串口桥终端。面板显示“最近一次角度读取失败”，断开或成功重连后仍保留；
无法读取状态时明确显示通信失败，不以状态码 0 代替未知错误，不自动恢复带力输出。

正常连接下，任一挡墙的“已卸力”状态都立即转为 **30** 的朝 50 mm 回弹，
即使实际角度暂时超出 0–50 mm 映射范围也不留空力区：按实测角度到标定 50 mm 的方向回弹。
回到 50 mm 附近一个编码器计数内，转为力度 30 的位置保持，避免继续冲过端点。
有效硬墙仍优先；故障、角度无效、断连、超时和停止状态继续卸力，不触发回弹。
